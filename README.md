# instructBase · תכנית הדרכה תקשוב גדודית

מצגות ודפי הנחיה למדריך במסלולי רדיו, רשתות ומכשירים. נקודת הכניסה היא `index.html`.

| תיקייה | מה יש בה |
|---|---|
| `index.html`, `radio/`, `networks/`, `devices/`, `reference/` | הסט שמתפרסם: מצגת HTML עצמאית ו-PDF לכל שיעור, ודפית הטכנאי. |
| `editor/` | עורך HTML לטעינה, עריכה ושמירה של המצגות, מקורות דפי ההנחיה והאינדקס, וליצירת שיעורים חדשים. הוראות ב-[`editor/README.md`](editor/README.md). |
| `archive/` | עותקים קפואים של כל החומר, ו-ZIP להורדה. ראו [`archive/README.md`](archive/README.md). |
| `techGame/` | משחק התרגול (בנוי). |
| `agents.md`, `.agents/` | הנחיות והערות עבודה פנימיות. לא חלק מהסט שמתפרסם. |

להורדת כל החומר כקובץ אחד: `archive/instructbase-2026-11-03.zip`, או כפתור ZIP בעורך.
