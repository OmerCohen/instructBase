מטרת השיעור

ללמד בחירת כלי לפי שאלה והפקת ראיה מדויקת, בלי להפוך את השיעור לרשימת פקודות לשינון.

מה החניך צריך לדעת

בסיום החניך יתאים כלי לשאלת אבחון, יקרא את השדה הרלוונטי, ויגדיר מה התוצאה מוכיחה ומה עדיין לא.

הכנה מראש

  • לוודא את זמינות הפקודות בגרסת Windows המקומית.
  • להכיר חלופת GUI כאשר PowerShell cmdlet אינו קיים.
  • להשתמש בכתובות ושמות דוגמה בלבד, ללא נתונים רגישים.

היקף השיעור

לא משנים הגדרות מערכת, לא מריצים כלים חיצוניים ולא מנתחים את כל פלט הפקודה. מחפשים שדה ממוקד.

פתיחה מומלצת

איזו פקודה תריץ כדי לענות על השאלה "האם Windows רואה Link", ומה היא עדיין לא מוכיחה?

01 · בחירת כלי

מתחילים בשאלה מדויקת ואז בוחרים פקודה

הכלי מספק נתונים לאבחון. תוצאה תקינה מצמצמת את החיפוש לשלב הבא, ותוצאה חריגה מקבלת משמעות מול ציפייה.

Linkכתובתשכןמסלולשם ופורטזהות
Get-NetAdapter ipconfig /all arp -a route / tracert DNS / Test-NetConnection w32tm / nltest / klist
בוחרים כלי לפי השאלה,
לא לפי ההרגל.

הסדר הוא מפת שאלות, לא הוראה להריץ את כל הפקודות בכל אירוע.

איך להעביר

בכל כלי אמור בקול: השאלה, השדה שעונה עליה, ומה התוצאה אינה מוכיחה.

02 · זהות מקומית

Get-NetAdapter ו-ipconfig מראים מה Windows רואה

Get-NetAdapter מציג מתאם, Status, קצב קישור ו-MAC. ipconfig /all מציג כתובת, מסכה, Gateway, DNS ומצב DHCP.

כל שדה מקבל משמעות
רק מול תכנון או ייחוס תקין.

פלט לדוגמה: ipconfig /all

שדהערך לדוגמה
IPv4 Address10.20.30.15
Default Gateway10.20.30.1
DNS Servers10.20.10.10

בסביבה סטטית, הערכים חייבים להתאים לתכנון, לא רק להיראות סבירים.

זהירות

Status Up אינו מוכיח VLAN, IP או דרך.

בדוק את המתאם הפעיל הנכון; מתאמים וירטואליים יכולים להטעות.

03 · שכנות ומסלול

Ping, ARP, route ו-tracert עונים על שאלות שונות

Ping / ARP

Ping בודק תגובת ICMP ו-RTT. arp -a מציג מיפוי IP מקומי ל-MAC לאחר שהייתה תעבורה.

route / tracert

route print מציג את החלטת התחנה. tracert מציג מי השיב לאורך הדרך ותלוי בתגובות ציוד ביניים.

תחנהנתבשרת
IP יעדטבלת ניתובIP יעד

בדרך: ARP מאתר את ה-MAC של השער, ובכל קפיצה נבנית מסגרת Ethernet חדשה.

כתובות IP נשארות מקצה לקצה;
כתובות MAC מתחלפות בכל קישור.

כוכבית או חוסר תגובה ב-tracert אינם בהכרח הפסקת העברת תעבורה.

זהירות

רשומת ARP חסרה לבדה אינה תקלה; ייתכן שעדיין לא נשלחה תעבורה ליעד.

04 · שם ופורט

Resolve-DnsName ו-Test-NetConnection מפרידים שם משירות

ב-DNS מחפשים מי ענה, איזה שם נשאל, סוג רשומה והכתובת שהוחזרה. בבדיקת פורט מחפשים כתובת מרוחקת, פורט ותוצאת TCP.

תחנהDNSשרת
server.unitשם ← כתובת10.20.40.25

בדיקת DNS עונה תחילה על השאלה מה הכתובת, ורק לאחר הפתרון נבדק השירות בכתובת שהוחזרה.

בדיקת שם קודמת לבדיקת פורט כאשר המשתמש פונה בשם.

מה לא הוכח

TcpTestSucceeded=True מוכיח שנפתח TCP ליעד ולפורט; הוא אינו מוכיח שהיישום החזיר תוכן תקין.

05 · Domain, תעודה ואירועים

זמן, איתור DC, כרטיסים ואמון משלימים את התמונה

w32tm /query /status בודק זמן ומקור; nltest /dsgetdc:domain בודק איתור DC; klist מציג כרטיסי Kerberos. תעודה ואירועים נותנים שם, תוקף, מנפיק ורצף בזמן.

DNSזמןKerberosהרשאה
איתור DCתוקף כרטיסאימותקבוצות

Certificate: שם · תוקף · מנפיק · שרשרת

TLS מתחיל באימות השרת ורק אחר כך בהצפנת התעבורה.

Event Viewer מקבל משמעות כאשר מתעדים שעה, מקור, Event ID והודעה מלאה.

חלופה

אם כלי PowerShell אינו קיים בגרסה המקומית, השתמש בחלון המקביל; השאלה והשדה נשארים זהים.

מילון קצר למדריך

Status Up: המתאם רואה קישור.

Route: כלל בחירת דרך.

Established: חיבור TCP שנוצר.

Event ID: מזהה סוג אירוע.

RTT: זמן הלוך ושוב.

Listener: שירות שמאזין לפורט.

SRV: רשומת DNS לאיתור שירות.

Cache: מידע שמור זמנית.
