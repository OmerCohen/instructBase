## 4. תקלות נפוצות במ.ק. 710 (`sheet-710-faults.jpg`)

  `FNC → ENT → CLR → CLR → CLR → ENT → SEC → ENT`

  `SEC → ENT`

**בעיה: כשאני מנסה לצאת לשידור אני שומע צפצוף, ומופיעות המילים NO KEYS בתחתית המסך**

  `FREQ → CLR → ENT → CLR → ENT`
